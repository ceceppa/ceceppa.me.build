About Alessandro Senese (Ceceppa)

Alessandro Senese (Ceceppa) is a software engineer building open-source tools for React Native accessibility, Godot animation and AI-assisted development.

I’m Alessandro Senese, also known online as Ceceppa. I’m a software engineer and open-source developer focused on accessibility, developer tooling and AI-assisted development.

I like building tools that make complex things easier to work with without hiding what’s happening underneath. That means better accessibility, less unnecessary process, faster feedback loops and keeping people in control of the tools they use.

What I work on

A lot of my work starts with a problem I encounter myself and turns into an open-source project.

  • React Native AMA is an accessibility toolkit for React Native. I’m its original author and continue to develop it around the practical problems teams encounter when building accessible mobile applications.
  • Mano explores a human-controlled approach to AI-assisted software development: small phases, fast feedback and explicit decisions instead of handing an entire project over to an agent.
  • Anima is an animation library for Godot focused on making expressive animations easier to compose and reason about.

My interests also extend into developer experience, software architecture, game development and the changing role of engineers as AI becomes part of everyday software development.

How I think about software

  • Accessibility belongs in engineering from the start, not bolted on at the end. That’s the idea behind React Native AMA.
  • AI should make engineers more capable, not reduce engineering to approving whatever an agent produces. That’s the idea behind Mano.
  • Good tools reduce cognitive load without removing control, and small feedback loops usually beat large upfront specifications.
